# cryptomcp

MCP-сервер рыночного контекста Binance USDⓈ-M Futures для анализа с помощью ИИ.

Реализует модули A1 (data_fetcher) и A2 (metrics) из ТЗ `crypto-scanner-architecture.md`
плюс расширение §12 (фандинг и открытый интерес). Полное описание решений и их
обоснований — в [PLAN.md](PLAN.md).

**Принцип: агрегаты считает код, структуру читает модель.** Индикаторы,
перцентили и сезонные поправки — детерминированный Python, покрытый тестами.
Интерпретация формы — работа модели, которой отдаются сырые свечи.

---

## Что он делает

Три уровня выдачи. Модель идёт сверху вниз и останавливается, как только хватит.

| Инструмент | Уровень | Назначение |
|---|---|---|
| `get_market_snapshot` | L1 | Общая картина: лестница таймфреймов, уровни, пивоты, деривативы, индекс |
| `get_squeeze_metrics` | L2 | Пять групп признаков ТЗ §4.2, каждое число с базой сравнения |
| `get_klines` | L3 | Сырые закрытые свечи (≤50) — когда важна форма, а не агрегат |
| `get_key_levels` | — | Кластеры S/R, недельные и дневные пивоты, POC и Value Area |
| `get_derivatives` | — | Фандинг в годовых, открытый интерес, классификация «цена × OI» |
| `scan_pairs` | — | Пакетное сканирование по squeeze_index |
| `list_symbols` | — | Отбор перпетуалов по обороту |

## Чего он не делает

Не предсказывает направление, не даёт торговых рекомендаций и не умеет
торговать. В проекте нет ни одного API-ключа, а все торговые эндпоинты Binance
требуют подписи — торговые операции невозможны конструктивно, а не по
договорённости.

`squeeze_index` измеряет готовность к движению, а не его сторону. Это эвристика
с неоткалиброванными весами; её прогностическая ценность неизвестна, пока не
накопится статистика.

## Установка

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -e ".[dev]"
```

Требуется Python 3.12+. Разрабатывается и разворачивается на 3.14 — pandas 3.0
и numpy 2.5 ставятся туда колёсами без сборки.

На Windows консоль по умолчанию cp1252, и вывод с кириллицей падает с
`UnicodeEncodeError`. Перед запуском скриптов:

```bash
export PYTHONIOENCODING=utf-8
```

## Проверка

```bash
pytest -q && ruff check cryptomcp/ tests/
```

Тесты не ходят в сеть: всё считается на синтетических рядах с известным
ответом, поэтому прогон не зависит от доступности биржи и не расходует лимит.

## Локальный запуск (stdio)

```bash
python -m cryptomcp.server
```

Регистрация в Claude Code:

```bash
claude mcp add cryptomcp -- /полный/путь/.venv/Scripts/python -m cryptomcp.server
```

## Удалённый запуск (HTTP)

```bash
MCP_AUTH_TOKEN=$(openssl rand -hex 32) CRYPTOMCP_TRANSPORT=streamable-http python -m cryptomcp.server
```

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `CRYPTOMCP_TRANSPORT` | `stdio` | `stdio` или `streamable-http` |
| `CRYPTOMCP_PORT` | `8000` | Порт HTTP-режима |
| `CRYPTOMCP_PUBLIC_HOST` | `0.0.0.0` | Домен за прокси (проверка заголовка Host) |
| `MCP_AUTH_TOKEN` | — | Bearer-токен. Без него сервер отвечает без аутентификации |
| `CRYPTOMCP_CONFIG` | — | Путь к YAML с порогами, см. `config.example.yaml` |
| `CRYPTOMCP_LOG_LEVEL` | `INFO` | Уровень лога (всегда в stderr) |

`/health` открыт без токена, `/mcp` требует `Authorization: Bearer <токен>`.

```
server.py      семь инструментов MCP
```

## Решения, которые легко нарушить по неосторожности

Каждое сопровождается тестом; ниже — зачем они нужны.

**Незакрытая свеча отсекается на входе, в `series.py`.** Её объём и диапазон
неполные, поэтому любая метрика поверх смещена. Отсечение сделано так, что ни
один индикатор физически не может её увидеть. Закрытость определяется по часам
биржи (расхождение с локальными измерялось в 1.5 секунды) с запасом в 5 секунд.

**Ни одно число не печатается без базы сравнения.** Перцентиль требует и ≥60
наблюдений, и ≥60 суток охвата; иначе печатается причина, а не значение.
Единственное исключение — открытый интерес: биржа хранит его историю только
30 суток, и оговорка едет вместе со значением.

**Объём считается в котируемой валюте (USDT), не в базовой.** Иначе на паре,
выросшей втрое, объём «падает» просто потому, что за те же деньги покупают
меньше монет.

**Объём сравнивается с сезонной базой.** У крипты сильная суточная сезонность,
и плоская MA20 показывала бы «затухание» там, где просто ночь. При этом форма
суток берётся с длинного окна, а уровень — со свежего: наивная медиана слота за
60 суток смешивает сезонность с дрейфом активности и завышает показания вдвое.

**Динамика OI считается по числу контрактов, не по стоимости.** При росте цены
на 5% стоимость OI вырастет на те же 5%, даже если ни одна позиция не открылась.

**Группа без достаточной базы исключается из индекса, а не обнуляется**, веса
оставшихся перенормируются. Ноль означал бы «признака нет», хотя его не удалось
измерить.

**При изменении весов поднимать `SQUEEZE_FORMULA_VERSION`.** Без этого записи
журнала до и после калибровки станут несопоставимы, и накопленное пропадёт.
